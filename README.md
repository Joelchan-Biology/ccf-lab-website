# CCF Lab Website

Academic lab website for the Cheok Chit Fang Lab at NUS Pathology and IMCB, A*STAR.

**Live:** [cheokchitfanglab.com](https://cheokchitfanglab.com)

## Development

```bash
npm install
npm run dev
```

## Deployment

Static export deployed on Cloudflare Pages. Pushes to `main` trigger automatic builds.

```bash
npm run build   # outputs to /out
```
